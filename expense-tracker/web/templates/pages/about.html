О проекте

«Учёт личных трат» — учебное веб-приложение на Go. Пользователь регистрируется, добавляет расходы с категориями, фильтрует их и смотрит статистику.

Технологии

  • HTTP-сервер — стандартный пакет net/http (маршрутизатор http.ServeMux, Go 1.22+);
  • шаблоны — html/template (автоматическое экранирование, защита от XSS);
  • база данных — SQLite через database/sql (драйвер modernc.org/sqlite);
  • авторизация — сессии в cookie, пароли хэшируются через bcrypt;
  • графики — Chart.js + fetch() к JSON API.

Служебный маршрут для проверки: /ping (отвечает pong).
